Grok Desktop Portable

A local Work interface for the Grok Build CLI you already installed. One bridge binary runs on your machine and serves the UI over loopback. This page is only for download and docs — it never runs your agent. 

curl -fsSL https://desktop.grok.me/install.sh | sh

Windows (PowerShell): irm https://desktop.grok.me/install.ps1 | iex

Requirements

  • Grok Build CLI installed and authenticated (grok)
  • Chrome, Edge, or Firefox 84+ (Safari is not supported)
  • Linux, Windows, or macOS

First run

grok-bridge doctor
grok-bridge serve
# other terminal:
grok-bridge open

What this is not

  • Not the full Electron Grok Desktop app
  • Not a sandbox or remote execution product
  • Not a CDN-hosted app talking to localhost

The bridge runs with the same authority as your CLI, including plugins, hooks, and MCP servers you configured. Read the threat model.

Verify

Releases are unsigned FOSS binaries. Prefer checking checksums.txt on the GitHub release against the file you downloaded, and audit the matching source tag.

macOS may quarantine unsigned downloads; Windows SmartScreen may warn. After checksum verification you can open the binary explicitly.
